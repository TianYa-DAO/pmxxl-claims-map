# 使用说明：领地小地图模组（客户端）

## 1. 两种工作模式（自动切换）

1. 服务端装了 PmxxlClaims 插件：服务端把附近 16 区块（可配 1-32）内的领地推给客户端，客户端直接画；10 秒一次心跳，内容不变也发，保证客户端始终知道"服务端有插件"。
2. 服务端没装插件：自动降级为聊天兜底——走进没记录过的区块时静默问一次 /res show，解析回显坐标，本地记录并持久化。
3. 两种数据在地图上合并显示；推流生效时兜底自动停用。

## 2. 安装

1. 前置：Fabric Loader 0.20.1、MC 1.21.11、Fabric API 0.141.6+。
2. 把 pmxxlclaims-mod-1.0.0.jar 放进 .minecraft/mods/。

## 3. 用法

1. M 键开关小地图（右上角，默认 128×128，1 像素 1 格，北向上），开关状态会持久化。
2. 小地图颜色：越界色块裁剪、主领地描边 2 像素、子领地描边 1 像素，领地名字在色块够大时居中显示。

## 4. 配置 config/pmxxlclaims.json

1. autoScan：兜底查询开关，默认 true。
2. intervalMs：兜底查询最小间隔，默认 1500。
3. showCount：左上角 claims 计数，默认 true。
4. minimapVisible：小地图开关状态。
5. minimapSize / minimapMargin：小地图尺寸与边距。
6. claimAlpha：领地填充透明度（0-255），默认 102。

## 5. 数据文件

config/pmxxlclaims-claims.json：兜底模式记录的领地，按维度保存，最多 2000 条，按更新时间淘汰，异步写盘。

## 6. 能力边界

1. 推流覆盖范围 = 服务端配置的半径，超出不显示。
2. 兜底只能记录走过/问过的领地。
3. 全服一次全显示只能靠服务端调大半径，或未来接 Pl3xMap/dynmap 数据源。

## 7. 验收

1. 走进自己领地，地图色块与实际范围误差 ≤1 格。
2. 聊天里看不到被解析的 /res show 回显。
3. 走出领地再回来不会重复请求（已知范围内不请求）。
4. 退出重进，兜底记录还在。
5. M 键开关并重启游戏后状态保持。
