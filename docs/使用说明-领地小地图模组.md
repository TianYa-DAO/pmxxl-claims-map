# 使用说明：领地小地图模组（客户端）

## 1. 数据来源

1. 只认服务端推送：服务端装了 PmxxlClaims 插件后，把玩家附近 16 区块（可配 1-32）内的领地打包推给客户端，客户端直接画。
2. 模组不会发送任何游戏内命令，也不解析聊天；服务端没装插件时，地图上不显示领地。
3. 服务端每 10 秒心跳一次，内容不变也发，客户端据此判断服务端在线并维持数据。

## 2. 安装

1. 前置：Fabric Loader 0.20.1、MC 1.21.11、Fabric API 0.141.6+。
2. 推荐装 Xaero's Minimap 1.21.11-26.6.x（Fabric），领地会画在 Xaero 小地图上；没装则用模组自带的简易小地图。
3. 把 pmxxlclaims-mod-1.0.0.jar 放进 .minecraft/mods/。

## 3. 用法

1. M 键开关小地图（右上角，默认 128×128，1 像素 1 格，北向上），开关状态会持久化。
2. 装了 Xaero 时以 Xaero 为准，领地显示在 Xaero 小地图上；Xaero 小地图没开/没画出来时，自带 HUD 会在 1 秒内接管。
3. 主领地描边 2 像素、子领地描边 1 像素，领地名字在色块够大时居中显示。

## 4. 配置 config/pmxxlclaims.json

1. showCount：左上角 claims 计数，默认 true。
2. minimapVisible：小地图开关状态。
3. minimapSize / minimapMargin：小地图尺寸与边距。
4. claimAlpha：领地填充透明度（0-255），默认 102。
5. xaeroScale：Xaero 后端色块尺寸系数，默认 1.0；色块比实际领地大就调小、小就调大。

## 5. 能力边界

1. 显示范围 = 服务端配置的半径，超出不显示。
2. 全服一次全显示只能靠服务端调大半径，或未来接 Pl3xMap/dynmap 数据源。
3. 服务端没装插件时没有领地数据可显示。

## 6. 验收

1. 走进自己领地，地图色块与实际范围误差 ≤1 格。
2. 游戏内聊天没有任何被模组触发的命令回显。
3. M 键开关并重启游戏后状态保持。
4. 装了 JourneyMap 时，JM 小地图与全屏地图都能看到领地。
